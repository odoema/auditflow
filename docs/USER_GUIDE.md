# AuditFlow User Guide (MVP)

## For Audit Partners & Managers
Dashboard shows active audits, outstanding requests, open review notes, overdue tasks.

## Clients
+ New Client creates Drive structure + Sheets record automatically.

## Document Requests
Create request → client receives secure upload link → file lands in correct Drive folder → status becomes Received.

## Working Papers
Templates become real Google Docs in the correct section folder. Open Working Paper opens the actual Google Doc.

## Review Workflow
Prepared → Submitted for Review → Manager Review → Review Notes → Auditor Response → Resolved → Approved.

## Tasks
Kanban board: TODO, IN PROGRESS, SUBMITTED, UNDER REVIEW, COMPLETED, OVERDUE.

## Audit AI Assistant
Natural language help for missing documents, review notes, tasks. Always labelled as AI-generated assistance requiring professional review.

## Client Portal
Mobile-friendly checklist. Token-based. No login required for upload.
