# AuditFlow Roadmap

## MVP (Current)
- Responsive dashboard, Clients, Engagements, Documents, Requests, Working Papers, Review, Tasks, AI Assistant, Demo data, GitHub Pages + Actions, Apps Script structure.

## Phase 2
Live Apps Script + real Sheets/Drive, email notifications, role-based views, hardened client tokens, basic reporting.

## Phase 3
WhatsApp/SMS, AI classification on upload, controlled AI summarisation of Drive files, multi-firm support.

## Later
Methodology engine, banking integrations, SSO, billing, multi-country packs.

Core principle remains: Google Drive is system of record; AuditFlow is the intelligent layer.
