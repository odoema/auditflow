# AuditFlow

**Intelligent Audit Document & Workflow Management System**

One intelligent workspace for managing audit clients, documents, working papers, requests, reviews and audit workflows — powered by Google Workspace, GitHub and AI.

## Live Demo

- **App**: [https://odoema.github.io/auditflow](https://odoema.github.io/auditflow)
- **Client Portal**: [https://odoema.github.io/auditflow/client-portal.html](https://odoema.github.io/auditflow/client-portal.html)

## Philosophy

Google Drive remains the system of record.  
AuditFlow is the intelligent interface and workflow layer on top of the tools an audit firm already owns.

```
Google Drive + Google Docs + Google Sheets + Apps Script + GitHub Pages + AI
```

## Features (MVP)

- Dashboard with live metrics
- Client & Engagement management
- Automatic Google Drive folder structure
- Document Request system + mobile client upload portal
- Working Paper register (Google Docs)
- Review Notes workflow
- Task board
- Activity Log
- Audit AI Assistant (multi-provider abstraction)
- Fully responsive
